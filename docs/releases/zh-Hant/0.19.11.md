# 0.19.11

Windows 伺服器版本 **0.19.11**，Android 應用程式版本 **0.18.13**（組建 **72**）。

## 新增

- Android 聊天現在可顯示行內和獨立區塊中的 LaTeX 公式。

## 修正

- 透過 Claude 的 `SendUserFile` 新附加的影片，在 Claude 清除暫存檔後仍可播放。
- 如果在 PC 上找不到影片檔案，Android 應用程式會提示重新附加。

## 下載

- Windows x64 — `remote-code-v0.19.11-win32-x64.zip`
- Android — `remote-code-v0.18.13.apk`
