# 0.19.25

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.19.25.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.19.25.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.19.25.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.19.25.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.19.25.md)

Windows 伺服器 **0.19.25**，Android 應用程式 **0.18.26**（組建 **85**）。

## 新增

- 在 Claude 工作流程中檢視子代理程式的活動和對話，有記錄時也會顯示權杖用量。
- 配對多台電腦，並在電腦歷程記錄頁面切換連線。
- 在聊天中附加單檔最大 512 MiB 的檔案，並查看上傳進度。
- 透過熱圖檢視整個工作階段的快取命中率。
- Antigravity 聊天的背景 Shell 命令仍在執行時，可將該聊天保留在使用中清單。

## 變更

- 放大遠端桌面後，小幅移動游標時畫面保持不動。雙指滑動更短的距離即可開始捲動。
- 第二次點按時按住或移動手指即可開始拖曳。連線中斷後，伺服器會放開滑鼠按鍵。
- 縮小了 Android 下載檔案，並簡化了 Git 概觀、聊天和設定頁面。

## 修正

- 影片串流播放失敗時，從暫時下載的檔案重新嘗試播放。
- 修正開啟已變更檔案的問題。返回專案檔案瀏覽器時恢復先前的資料夾，並防止短檔案的程式碼縮圖遭到拉伸。
- 在執行中的 Antigravity 工作階段套用權限變更。
- 修正 Claude 聊天中的首次額外提問失敗的問題，並改善電腦登入認證資訊變更後使用 Remote Control 傳送訊息的體驗。

## 下載

- Windows x64 — `remote-code-v0.19.25-win32-x64.zip`
- Android — `remote-code-v0.18.26.apk`
