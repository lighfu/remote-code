# 0.19.10

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.19.10.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.19.10.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.19.10.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.19.10.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.19.10.md)

Windows 伺服器版本 **0.19.10**，Android 應用程式版本 **0.18.11**（組建 **70**）。

## 新增

- 在 Android 上的遠端桌面聆聽 Windows PC 的播放音訊。
- 在 PC 歷史紀錄全新的「全部」分頁中，集中搜尋、排序並開啟 Claude、Codex 和 Antigravity 對話。 在 PC 歷史紀錄中一次展開或摺疊所有專案群組。
- 在 Git 畫面中對變更的檔案進行排序，並根據變更內容產生可編輯的提交訊息。
- 可選擇要在聊天輸入框下方顯示哪些輸入、輸出、快取與費用數據。聊天頁尾與快取詳細資訊中亦會顯示換算後的當地貨幣金額。應用程式會根據語言選擇貨幣，您也可以在「設定」中自行選擇。
- 輕觸附加的圖片或影片以在傳送前預覽，接著在附件之間滑動切換。

## 變更

- 遠端桌面現預設採用 30 FPS 原生解析度，並啟用清晰像素縮放、剪貼簿同步與 PC 音訊。
- 使用右上角的聊天選單變更思考與工具詳細資訊的顯示方式，或切換工具輸入、工具輸出、檔案及 Git diff 的自動換行。進行變更時選單會保持開啟。
- 在聊天變更卡片中一次展開多個檔案的差異。 針對文字檔案，「以十六進位檢視」現已位於程式碼檢視器的右上角選單中。
- 現可在終端機清單中查看完整指令，並透過各終端機的 × 按鈕將其關閉。
- 在「設定」中，已安裝的伺服器相依項目名稱旁現已顯示勾選標記。
- 上下文、快取以及 Git 檔案與行數現在會在聊天頁尾和詳細資訊檢視中即時更新。
- 拖曳捲軸即可瀏覽網路記錄。
- 終端機清單現直接顯示於標題下方。移除了 Git 畫面中的兩行說明文字，並在模型選項說明與開關之間增加了間距。

## 修正

- 更快速載入 Claude 歷程記錄與 Git 狀態，並在網路未變更時於 Android 上重複使用最近的 DNS 查詢。
- 在聊天工具卡片中，每個指令或工具輸入僅顯示一次。
- 從封存返回時，回到先前查看的清單。
- 新的 Antigravity 對話現在會顯示其模型名稱。
- Codex 快取詳細資料現在會顯示預估節省金額。
