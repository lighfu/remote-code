# 0.19.9

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.19.9.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.19.9.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.19.9.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.19.9.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.19.9.md)

Windows 伺服器版本 **0.19.9**，Android 應用程式版本 **0.18.9**（組建 **68**）。

## 新增

- 在 Android 上的遠端桌面聆聽 Windows PC 的播放音訊。
- 在 PC 歷史紀錄全新的「全部」分頁中，集中搜尋、排序並開啟 Claude、Codex 和 Antigravity 對話。
- 在 Git 畫面中根據變更產生可編輯的提交訊息。

## 變更

- 遠端桌面現預設採用 30 FPS 原生解析度，並啟用清晰像素縮放、剪貼簿同步與 PC 音訊。
- 使用右上角的聊天選單變更思考與工具詳細資訊的顯示方式，或切換工具輸入、工具輸出、檔案及 Git diff 的自動換行。進行變更時選單會保持開啟。
- 在聊天變更卡片中一次展開多個檔案的差異。
- 現可在終端機清單中查看完整指令，並透過各終端機的 × 按鈕將其關閉。
- 在「設定」中，已安裝的伺服器相依項目名稱旁現已顯示勾選標記。

## 修正

- 更快速載入 Claude 歷程記錄與 Git 狀態，並在網路未變更時於 Android 上重複使用最近的 DNS 查詢。
- 在聊天工具卡片中，每個指令或工具輸入僅顯示一次。
- 從封存返回時，回到先前查看的清單。

## 下載

- Windows x64 — `remote-code-v0.19.9-win32-x64.zip`
- Android — `remote-code-v0.18.9.apk`
