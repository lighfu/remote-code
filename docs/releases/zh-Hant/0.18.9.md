Windows 伺服器 **0.18.9** 與 Android 應用程式 **0.17.11**（建置 **58**）。

## 新增

- 從伺服器儀表板或 Android 設定安裝 Claude Code、Codex、Antigravity CLI 與 cloudflared。
- 繁體中文 README 與版本資訊。

## 變更

- 優先使用 WinGet，並以通過驗證的官方 Windows 下載作為備援。
- 將已載入的 Claude 技能與使用者訊息分開顯示，並保留完整內容。

## 修正

- 恢復 Claude 問題選項，並防止訊息與思考區塊重複。
- 安裝相依套件後重新整理供應商可用狀態並啟動 Quick Tunnel。

## 下載

- Windows x64: `remote-code-v0.18.9-win32-x64.zip`.
- Android: `remote-code-v0.17.11.apk`.
