# 0.18.9

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.18.9.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.18.9.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.18.9.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.18.9.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.18.9.md)

Windows 伺服器 **0.18.9** 與 Android 應用程式 **0.17.11**（build **58**）。

## 新增

- 可從伺服器儀表板的 **5 Setup** 分頁或已連線 Android 應用程式的設定中安裝 Claude Code、Codex、Antigravity CLI 與 cloudflared。兩處皆會顯示安裝進度、錯誤訊息與重試控制項。
- 新增繁體中文 README 與在地化版本資訊卡片。

## 變更

- 相依套件安裝優先使用使用者範圍的 WinGet 套件。當 WinGet 無法使用或無法完成安裝時，安裝程序會改用各提供者的官方原生 Windows 下載檔案、驗證其雜湊值（checksum），並檢查已安裝的 CLI 是否能正常啟動。代理程式帳號登入則在 PC 上進行。
- 已載入的 Claude 技能會以獨立卡片顯示完整內容，與使用者訊息分開呈現。既有已匯入的技能訊息會透過原始對話紀錄進行修復。

## 修正

- 新安裝的 CLI 無需重新啟動伺服器即可偵測到。安裝 cloudflared 後，會啟動先前請求的 Quick Tunnel，且不會建立重複的通道工作程序。
- Claude 的下一步提問現在會在應用程式中顯示回覆選項，同時保留原始的工具輸入與輸出內容。
- 防止單一回應同時透過串流與多筆對話紀錄列傳入時，產生重複的 Claude 訊息與思考區塊。合理的重複訊息則會完整保留。
- 防止安裝成功後仍殘留過期的提供者可用狀態，並防止來自儀表板與應用程式的安裝請求互相重疊。

## 下載

- Windows x64: `remote-code-v0.18.9-win32-x64.zip`（包含編譯好的 Go 伺服器、相依套件安裝程式與 Android APK）。
- Android: `remote-code-v0.17.11.apk`。
