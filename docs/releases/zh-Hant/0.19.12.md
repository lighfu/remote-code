# 0.19.12

Windows 伺服器版本 **0.19.12**，Android 應用程式版本 **0.18.13**（組建 **72**）。

## 修正

- 在 Windows 可攜版中按 `R` 鍵重新啟動時，現在會檢查更新，並在有新版本時詢問是否安裝。
- 無法檢查更新時，主控台會顯示提示。

若要從 0.19.11 或更早版本安裝此修正，請先停止伺服器，再執行 `start.cmd` 並確認更新。

## 下載

- Windows x64 — `remote-code-v0.19.12-win32-x64.zip`
- Android — `remote-code-v0.18.13.apk`
