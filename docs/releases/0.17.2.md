# Remote Code 0.17.2

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.17.2.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.17.2.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.17.2.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.17.2.md)

- When another server is running, offer to stop it and start the new instance or cancel the new startup.
- Keep the existing server when the prompt is left unanswered or startup is non-interactive.
- Add server download and link-sharing buttons in Android 0.17.5.
- Support Japanese, English, Simplified Chinese, Traditional Chinese, and Korean. Android 13 and later can switch languages in the app, while Android 10–12 follows the device language.
- Show Claude cross-session messages in dedicated cards and add reply text to the draft.
- Add separate word-wrap toggles for tool input and output.
- Make the Git changes list more compact.
- Add separate font settings for the interface, chat text, and code, with selection dialogs.

Use the new ZIP to access the startup option for stopping an existing server. If an older server without startup control support is running, press Ctrl+C in its terminal before starting the new version.
