# 0.19.25

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.19.25.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.19.25.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.19.25.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.19.25.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.19.25.md)

Windows server **0.19.25** and Android app **0.18.26** (build **85**).

## Added

- View Claude workflows, including subagent activity, conversations, and token usage when available.
- Pair with multiple PCs and switch between them from PC History.
- Attach files up to 512 MiB each in chat and see upload progress.
- View a heatmap of cache hit rates across the session.
- Keep Antigravity chats in the active list while a background shell command is still running.

## Changed

- The zoomed remote desktop stays still during small cursor movements. Two-finger scrolling starts with a shorter swipe.
- Hold the second tap or move your finger while it is down to start dragging. The server releases the button if the connection drops.
- Reduced the Android download size and simplified the Git overview, chat, and settings screens.

## Fixed

- Retry video playback from a temporary download if streaming fails.
- Open changed files reliably, return to the last folder in the project browser, and keep short code minimaps from stretching.
- Apply permission changes during an active Antigravity session.
- Fix the first side question in a Claude chat and improve Remote Control message delivery when PC sign-in credentials change.

- Android — `remote-code-v0.18.26.apk`
