# 0.18.0

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.18.0.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.18.0.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.18.0.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.18.0.md)

- Migrate the server to Go, removing the requirement to install or bundle Node.js.
- Use the Claude Code executable already installed on the PC. The distribution excludes the provider executable.
- Port conversations, approvals, history, usage, files, Git, terminals, and distribution updates.

To migrate from the Node.js version, stop the server, extract the new ZIP into a separate folder, and copy `data` from the old folder. Open `start.cmd` to start the server.

Includes the signed Android 0.17.6 APK.
