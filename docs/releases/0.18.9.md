# 0.18.9

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.18.9.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.18.9.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.18.9.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.18.9.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.18.9.md)

Windows server **0.18.9** and Android app **0.17.11** (build **58**).

## Added

- Install Claude Code, Codex, Antigravity CLI, and cloudflared from the server dashboard's **5 Setup** tab or the connected Android app's settings. Both show installation progress, errors, and retry controls.
- Added a Traditional Chinese README and localized release cards.

## Changed

- Dependency setup prefers user-scoped WinGet packages. When WinGet is unavailable or cannot complete installation, setup uses each provider's official native Windows downloads, verifies their checksums, and checks that the installed CLI starts. Agent account sign-in is performed on the PC.
- Loaded Claude skills appear in their own cards with their full content, separately from user messages. Existing imported skill messages are repaired using the original transcript.

## Fixed

- Newly installed CLIs are detected without restarting the server. Installing cloudflared starts a previously requested Quick Tunnel without creating duplicate tunnel workers.
- Claude next-step questions now show reply choices in the app while preserving the original tool input and output.
- Prevent duplicate Claude messages and thinking blocks when one response arrives through streaming and multiple transcript rows. Legitimate repeated messages remain intact.
- Prevent stale provider availability from surviving a successful installation and prevent overlapping installation requests from the dashboard and app.

## Downloads

- Windows x64: `remote-code-v0.18.9-win32-x64.zip` (compiled Go server, dependency installer, and Android APK).
- Android: `remote-code-v0.17.11.apk`.
