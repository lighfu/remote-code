# 0.19.9

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.19.9.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.19.9.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.19.9.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.19.9.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.19.9.md)

Windows server **0.19.9** and Android app **0.18.9** (build **68**).

## Added

- Listen to the Windows PC’s playback audio from Remote Desktop on Android.
- Choose All in PC history to search, sort, and open conversations across Claude, Codex, and Antigravity.
- Generate an editable commit message from your changes on the Git screen.

## Changed

- Remote Desktop now defaults to native resolution at 30 FPS, with sharp pixel zoom, clipboard sync, and PC audio enabled.
- Use the top-right chat menu to change how thinking and tool details are displayed, or toggle line wrapping for tool input, tool output, files, and Git diffs. The menu stays open between changes.
- Expand diffs for multiple files at once in a chat change card.
- Read the full command in the terminal list and close each terminal with its × button.
- Installed server dependencies have a checkmark beside their names in Settings.

## Fixed

- Load Claude history and Git status faster, and reuse recent DNS lookups on Android when the network is unchanged.
- Show each command or tool input only once in a chat tool card.
- Going back from the archive now returns you to the list you were viewing.
