# Remote Code 0.17.0

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.17.0.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.17.0.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.17.0.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.17.0.md)

## Changes

- Make code editing lighter and add a word-wrap toggle.
- Add a native Markdown preview.
- Add rounded corners and separators to menus and standardize the refresh action label.
- Show subagents while they are running and add a PC history heading.
- Check for server updates at startup, request approval, and download prebuilt APKs from GitHub. Defer updates while work is running and restore the previous version if an update fails.

## Installation and updates

Extract the Windows ZIP into a new folder and open `start.cmd`. Install the Android app using the terminal's app QR code, then scan the connection QR code in the app.

Includes Android 0.17.1 (build 48). Server updates require approval and target public stable Windows releases. Automatic server updates are disabled for development Git checkouts.
