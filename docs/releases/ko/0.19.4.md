# 0.19.4

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.19.4.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.19.4.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.19.4.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.19.4.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.19.4.md)

Windows 서버 **0.19.4** 및 Android 앱 **0.18.4** (빌드 **63**).

## 추가

- Android에서 모든 Windows 디스플레이를 한 번에 보거나, 하나를 선택하여 전체 해상도로 볼 수 있습니다.
- 터치 제스처로 클릭하거나 스크롤하고, 포인터를 중심으로 확대하거나 축소할 수 있습니다. 키보드로 입력하거나 클립보드 텍스트를 동기화할 수 있습니다.
- 목표 비트레이트를 설정하거나 앱이 자동으로 조정하도록 할 수 있습니다. 디버그 오버레이에는 프레임 레이트, 대역폭, 처리 시간 및 연결 이벤트가 표시됩니다.

## 변경

- 활성 대화 중 Git 상태 및 세션 컨텍스트의 로드 속도가 향상되었습니다.

## 다운로드

- Windows x64 — `remote-code-v0.19.4-win32-x64.zip`
- Android — `remote-code-v0.18.4.apk`
