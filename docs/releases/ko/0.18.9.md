# 0.18.9

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.18.9.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.18.9.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.18.9.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.18.9.md)

Windows 서버 **0.18.9** 및 Android 앱 **0.17.11**(빌드 **58**).

## 추가

- 서버 대시보드의 **5 Setup** 탭 또는 연결된 Android 앱의 설정에서 Claude Code, Codex, Antigravity CLI, cloudflared를 설치할 수 있습니다. 두 곳 모두 설치 진행 상황, 오류 및 재시도 컨트롤을 표시합니다.
- 번체 중국어 README와 현지화된 릴리스 카드를 추가했습니다.

## 변경

- 의존성 설치 시 사용자 범위의 WinGet 패키지를 우선 사용합니다. WinGet을 사용할 수 없거나 설치를 완료할 수 없는 경우, 각 제공자의 공식 네이티브 Windows 다운로드 파일을 사용하고 체크섬을 검증한 뒤 설치된 CLI가 시작되는지 확인합니다. 에이전트 계정 로그인은 PC에서 수행합니다.
- 로드된 Claude 스킬은 사용자 메시지와 분리되어 전체 내용이 담긴 개별 카드로 표시됩니다. 기존에 가져온 스킬 메시지는 원본 트랜스크립트를 사용해 복구됩니다.

## 수정

- 새로 설치된 CLI가 서버를 재시작하지 않아도 감지됩니다. cloudflared를 설치하면 중복 터널 워커를 생성하지 않고 이전에 요청된 Quick Tunnel을 시작합니다.
- Claude의 다음 단계 질문이 원본 도구 입력과 출력을 유지하면서 앱에 응답 선택지를 표시합니다.
- 하나의 응답이 스트리밍과 여러 트랜스크립트 행을 통해 도착할 때 Claude 메시지와 사고 블록이 중복되는 문제를 방지했습니다. 정상적인 반복 메시지는 그대로 유지됩니다.
- 설치 성공 후에도 이전 제공자 사용 가능 상태가 남아 있는 문제를 방지하고, 대시보드와 앱에서 설치 요청이 겹치지 않도록 방지했습니다.

- Android: `remote-code-v0.17.11.apk`.
