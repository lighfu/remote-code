# 0.18.3

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.18.3.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.18.3.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.18.3.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.18.3.md)

- Windows 서버를 Go로 이전했습니다. 배포 ZIP을 압축 해제하고 `start.cmd`로 시작할 수 있습니다.
- 터미널에서 연결용 QR과 앱용 QR을 표시합니다. QR을 표시할 공간이 부족하면 지원하는 터미널에서 창을 자동으로 넓힙니다.
- Codex, Claude, Antigravity의 컨텍스트 상세 정보, Codex 캐시 집계, Antigravity 모델 이름 표시를 수정했습니다.
- Codex Desktop이 작업 중이면 서버를 재시작하고 재연결을 기다리는 동안에도 작업 중 상태를 유지합니다.
- 서명된 Android 앱 0.17.8이 포함됩니다. 세션 표시 순서와 재연결 시 상태 갱신을 수정하고 한 줄짜리 생각 내용은 처음에 접어서 표시합니다.

이전 Node.js 버전에서 옮길 때는 이전 서버를 종료하고 새 ZIP을 별도 폴더에 압축 해제하세요. 이전 폴더의 `data`를 복사한 뒤 `start.cmd`로 시작합니다. Android 앱은 터미널의 **App QR**로 설치하고 업데이트할 수 있습니다.
