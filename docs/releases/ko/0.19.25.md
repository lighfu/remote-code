# 0.19.25

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.19.25.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.19.25.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.19.25.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.19.25.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.19.25.md)

Windows 서버 **0.19.25** 및 Android 앱 **0.18.26** (빌드 **85**).

## 추가

- Claude 워크플로에서 하위 에이전트의 활동과 대화를 볼 수 있습니다. 기록이 있으면 토큰 사용량도 표시합니다.
- 여러 PC를 연결하고 PC 기록 화면에서 연결 대상을 전환할 수 있습니다.
- 채팅에 파일당 최대 512 MiB를 첨부하고 업로드 진행률을 볼 수 있습니다.
- 히트맵에서 세션 전체의 캐시 적중률을 볼 수 있습니다.
- 백그라운드 셸 명령이 계속 실행되는 동안 Antigravity 채팅을 작업 중 목록에 유지할 수 있습니다.

## 변경

- 원격 데스크톱을 확대했을 때 커서를 조금 움직여도 화면은 그대로 유지됩니다. 두 손가락을 더 짧게 밀어도 스크롤이 시작됩니다.
- 두 번째 터치에서 손가락을 누르고 있거나 움직이면 드래그가 시작됩니다. 연결이 끊기면 서버가 마우스 버튼을 놓습니다.
- Android 다운로드 크기를 줄이고 Git 개요, 채팅, 설정 화면을 정리했습니다.

## 수정

- 동영상 스트리밍이 실패하면 임시로 내려받은 파일에서 재생을 다시 시도합니다.
- 변경된 파일을 열 때의 문제를 해결했습니다. 프로젝트 파일 탐색기로 돌아오면 이전 폴더가 표시되며, 짧은 코드의 미니맵이 늘어나지 않습니다.
- 실행 중인 Antigravity 세션에 권한 변경을 적용합니다.
- Claude 채팅의 첫 번째 추가 질문이 실패하던 문제를 해결하고, PC 로그인 인증 정보가 변경됐을 때 Remote Control 메시지 전송을 개선했습니다.

## 다운로드

- Android — `remote-code-v0.18.26.apk`
