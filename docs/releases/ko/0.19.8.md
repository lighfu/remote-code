# 0.19.8

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.19.8.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.19.8.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.19.8.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.19.8.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.19.8.md)

Windows 서버 **0.19.8** 및 Android 앱 **0.18.7** (빌드 **66**).

## 추가

- 드래그 가능한 코드 미니맵으로 소스 파일과 diff를 탐색합니다.
- 바이너리 파일을 16진수로 확인하고 바이트 오프셋으로 직접 이동합니다.
- 채팅 변경 카드에서 영향을 받는 파일을 확인하고 각 파일을 직접 엽니다.

## 수정

- 새로 생성된 파일의 채팅 미리보기에 줄 번호를 표시합니다.
- 긴 대화에서 Codex ‘간단 질문’의 지연 시간을 줄이고 스트리밍 답변이 도착하는 대로 표시합니다.

## 다운로드

- Windows x64 — `remote-code-v0.19.8-win32-x64.zip`
- Android — `remote-code-v0.18.7.apk`
