# Remote Code 0.17.0

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.17.0.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.17.0.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.17.0.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.17.0.md)

## 변경 사항

- 코드 편집을 가볍게 개선하고 줄바꿈 표시 전환을 지원합니다.
- Markdown 네이티브 미리보기를 추가했습니다.
- 메뉴에 둥근 모서리와 구분선을 추가하고 새로 고침 표기를 통일했습니다.
- 실행 중인 하위 에이전트부터 표시하고 PC 기록 제목을 추가했습니다.
- 서버 시작 시 업데이트 확인과 승인, GitHub에서 빌드된 APK 다운로드를 지원합니다. 작업 중에는 업데이트를 미루고 실패하면 이전 버전으로 복구합니다.

## 설치 및 업데이트

Windows ZIP을 새 폴더에 압축 해제하고 `start.cmd`를 실행하세요. 터미널의 QR 코드로 Android 앱을 설치한 뒤 연결용 QR 코드를 스캔하세요.

Android 앱 버전은 0.17.1(48)입니다. 서버 업데이트는 승인이 필요하며 Windows 배포판의 공개 정식 릴리스를 대상으로 합니다. 개발용 Git 체크아웃에는 적용되지 않습니다.
