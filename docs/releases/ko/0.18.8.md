# 0.18.8

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.18.8.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.18.8.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.18.8.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.18.8.md)

Windows 서버 0.18.8과 Android 앱 0.17.10(빌드 번호 57)을 배포합니다.

## 변경

- Codex Desktop의 모델, 추론 강도, Fast 모드 업데이트를 한 번의 요청으로 통합했습니다.

## 수정

- Android에서 대화 기록을 불러오는 동안 도착한 답변과 승인 카드를 유지하도록 수정했습니다.
- Codex Desktop이 수락한 메시지 본문과 첨부를 Android 입력란에서 지우고 전송 중에 편집한 초안은 보존하도록 수정했습니다.
- 대화 목록의 미리보기가 이전 메시지나 하위 에이전트의 출력으로 돌아가는 문제를 수정했습니다.
- Codex의 짧은 질문(`/btw`) 기록 저장을 복원하고 답변이 완료되면 바로 표시하도록 수정했습니다.
- Codex의 작업 중인 대화 재연결, 중지, 계획, 질문, 생성 이미지 미리보기를 수정했습니다.
- Claude PC 세션의 작업 상태, 계획 승인, 컨텍스트 상세 정보, 캐시 집계를 수정했습니다.
- Antigravity의 질문 답변 기능을 복원하고 연속된 턴의 답변과 생각을 분리하여 표시하도록 수정했습니다.
- Android에서 연 터미널의 스크롤 기록을 유지하고 터미널 크기 변경을 즉시 적용하도록 수정했습니다.
- 이전 버전의 APK 배포, Windows 포터블 시작과 비정상 종료 후 복구, Quick Tunnel 프로세스 종료 후 재시도를 수정했습니다.

서버의 **App QR**을 통해 Android 앱을 업데이트할 수 있습니다.
