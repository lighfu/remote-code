# 0.19.5

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.19.5.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.19.5.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.19.5.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.19.5.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.19.5.md)

Windows 서버 **0.19.5** 및 Android 앱 **0.18.5** (빌드 **64**).

## 추가

- 슬라이더를 사용하여 원격 데스크톱 프레임 레이트(1–60 FPS)와 수동 비트레이트(1–150 Mbps)를 조절할 수 있습니다.
- JPEG 디코딩 정밀도를 선택하거나 최신 프레임을 우선 처리하고, 확대 시 선명한 픽셀 경계를 표시할 수 있습니다.
- 구문 강조와 줄 번호로 파일, Git 및 채팅 변경 사항을 검토할 수 있습니다. 도구 카드의 입력과 출력은 각각 줄 바꿈 환경설정을 공유합니다.

## 변경

- Windows 서버에서 전체 해상도를 유지하면서 고해상도 JPEG 프레임을 더 빠르게 인코딩합니다.
- 일본어 앱 업데이트 라벨에 이제 “バージョン”이 일관되게 사용됩니다.

## 다운로드

- Windows x64 — `remote-code-v0.19.5-win32-x64.zip`
- Android — `remote-code-v0.18.5.apk`
