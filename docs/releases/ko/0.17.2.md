# Remote Code 0.17.2

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.17.2.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.17.2.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.17.2.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.17.2.md)

- 서버를 중복 실행하면 기존 서버를 중지하고 시작하거나 이번 실행을 취소할 수 있습니다.
- 입력하지 않거나 비대화형으로 실행하면 기존 서버를 유지합니다.
- 앱 0.17.5에 서버 다운로드와 링크 공유 버튼을 추가했습니다.
- 일본어, 영어, 중국어 간체, 중국어 번체, 한국어를 지원합니다. Android 13 이상에서는 앱에서 언어를 전환하고, Android 10~12에서는 기기 언어를 따릅니다.
- Claude의 세션 간 메시지를 전용 카드에 표시하고 답변을 초안에 추가합니다.
- 도구 입력과 출력의 줄바꿈을 각각 전환할 수 있습니다.
- Git 변경 목록을 간결하게 표시합니다.
- UI, 채팅 본문, 코드의 글꼴 설정을 나누고 선택 대화상자를 추가했습니다.

기존 서버 중지 기능은 새 ZIP을 사용하세요. 제어 기능을 지원하지 않는 이전 버전이 실행 중이면 해당 터미널에서 Ctrl+C를 누른 뒤 시작하세요.
