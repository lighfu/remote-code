# 0.19.10

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.19.10.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.19.10.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.19.10.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.19.10.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.19.10.md)

Windows 서버 **0.19.10** 및 Android 앱 **0.18.11** (빌드 **70**).

## 추가

- Android의 원격 데스크톱에서 Windows PC의 재생 오디오 듣기.
- PC 기록의 새로운 '전체' 탭에서 Claude, Codex, Antigravity 대화를 한곳에서 검색, 정렬하고 열 수 있습니다. PC 기록에서 모든 프로젝트 그룹을 한 번에 확장 또는 접기.
- Git 화면에서 변경된 파일을 정렬하고 변경 사항을 기반으로 편집 가능한 커밋 메시지 생성할 수 있습니다.
- 채팅 입력창 아래에 표시할 입력, 출력, 캐시 및 비용 수치를 선택할 수 있습니다. 채팅 푸터와 캐시 상세 정보에도 현지 통화로 환산한 금액이 표시됩니다. 통화는 언어에 따라 앱에서 자동으로 선택되며, 설정에서 직접 선택할 수도 있습니다.
- 첨부된 이미지나 동영상을 탭하여 전송 전에 미리 보고, 첨부 파일 사이를 스와이프하여 전환합니다.

## 변경

- 원격 데스크톱 기본 설정을 30 FPS 네이티브 해상도로 변경하고 선명한 픽셀 확대, 클립보드 동기화, PC 오디오를 활성화했습니다.
- 우측 상단 채팅 메뉴를 통해 생각 및 도구 세부정보 표시 방식을 변경하거나 도구 입력, 도구 출력, 파일, Git diff의 줄 바꿈을 전환할 수 있습니다. 항목을 변경하는 동안에도 메뉴는 열린 상태로 유지됩니다.
- 채팅 변경 카드에서 여러 파일의 diff를 한 번에 펼칠 수 있습니다. 텍스트 파일의 경우, 이제 코드 뷰어의 오른쪽 상단 메뉴에 '16진수로 보기'가 있습니다.
- 이제 터미널 목록에서 전체 명령어를 확인하고, 각 터미널의 × 버튼으로 닫을 수 있습니다.
- 설정에서 설치된 서버 종속 항목 이름 옆에 체크 표시가 나타납니다.
- 이제 채팅 바닥글과 세부정보 뷰에서 컨텍스트, 캐시, Git 파일 및 라인 수가 실시간으로 업데이트됩니다.
- 스크롤바를 드래그하여 네트워크 로그를 탐색할 수 있습니다.
- 터미널 목록이 제목 바로 아래에 표시됩니다. Git 화면에서 두 줄의 도움말 텍스트를 제거하고 모델 옵션 설명과 스위치 사이에 여백을 추가했습니다.

## 수정

- Claude 기록 및 Git 상태를 더 빠르게 로드하고, 네트워크가 변경되지 않은 경우 Android에서 최근 DNS 조회를 재사용.
- 채팅 도구 카드에서 각 명령 또는 도구 입력을 한 번만 표시합니다.
- 보관함에서 뒤로 갈 때 이전에 보던 목록으로 돌아갑니다.
- 새 Antigravity 대화에서 모델 이름이 표시됩니다.
- Codex 캐시 상세 정보에 예상 절감액이 표시됩니다.
