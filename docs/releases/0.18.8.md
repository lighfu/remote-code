# 0.18.8

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.18.8.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.18.8.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.18.8.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.18.8.md)

This release includes Windows server 0.18.8 and Android app 0.17.10 (build 57).

## Changed

- Combined Codex Desktop model, reasoning effort, and Fast mode updates into one request.

## Fixed

- Preserved replies and approval cards arriving while Android loads chat history.
- Cleared accepted Codex Desktop messages and attachments from the Android composer while preserving draft edits made during submission.
- Stopped conversation previews reverting to older messages or subagent output.
- Restored Codex quick-question (`/btw`) history persistence and displayed completed answers promptly.
- Fixed Codex active-chat reconnection, stopping, plans, questions, and generated-image previews.
- Corrected Claude PC session activity, plan approval, context details, and cache reporting.
- Restored Antigravity question responses and separated replies and reasoning from successive turns.
- Preserved Android terminal scrollback and applied terminal size changes immediately.
- Fixed legacy APK serving, portable Windows startup and crash recovery, and Quick Tunnel retries after process exit.

Update the Android app using **App QR** in the server console.
