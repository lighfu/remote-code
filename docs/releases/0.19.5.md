Windows server **0.19.5** and Android app **0.18.5** (build **64**).

## Added

- Adjust the Remote Desktop frame rate (1–60 FPS) and manual bitrate (1–150 Mbps) with sliders.
- Choose JPEG decode precision, prioritize the latest frames, or show sharp pixel edges when zooming in.
- Review file, Git and chat changes with syntax highlighting and line numbers. Tool cards share input and output line-wrapping preferences.

## Changed

- The Windows server encodes high-resolution JPEG frames faster while preserving full resolution.
- Japanese app update labels now use “バージョン” consistently.

- Android — `remote-code-v0.18.5.apk`
