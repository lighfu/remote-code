# 0.19.10

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.19.10.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.19.10.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.19.10.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.19.10.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.19.10.md)

Windows 服务端版本 **0.19.10**，Android 应用版本 **0.18.11**（内部版本 **70**）。

## 新增

- 在 Android 上的远程桌面中收听 Windows PC 的播放音频。
- 在 PC 历史记录新增的“全部”标签页中，集中搜索、排序并打开 Claude、Codex 和 Antigravity 对话。 在 PC 历史记录中一次性展开或折叠所有项目组。
- 在 Git 界面中对更改的文件进行排序，并根据更改内容生成可编辑的提交信息。
- 可选择在聊天输入框下方显示哪些输入、输出、缓存和费用数据。聊天页脚和缓存详情中也会显示换算后的本地货币金额。应用会根据语言选择货币，您也可以在“设置”中自行选择。
- 点击附加的图片或视频以在发送前预览，然后在附件之间滑动切换。

## 变更

- 远程桌面现默认采用 30 FPS 原生分辨率，并启用清晰像素缩放、剪贴板同步及 PC 音频。
- 使用右上角的聊天菜单更改思考过程和工具详情的显示方式，或切换工具输入、工具输出、文件以及 Git diff 的自动换行。更改设置时菜单保持打开状态。
- 在聊天变更卡片中一次性展开多个文件的差异。 对于文本文件，“以十六进制查看”现已位于代码查看器的右上角菜单中。
- 现可在终端列表中查看完整命令，并通过各终端的 × 按钮将其关闭。
- 在“设置”中，已安装的服务器依赖项名称旁现已显示勾选标记。
- 上下文、缓存以及 Git 文件和行数现在会在聊天页脚和详情视图中实时更新。
- 拖动滚动条即可浏览网络日志。
- 终端列表现直接显示在标题下方。移除了 Git 界面中的两行帮助文本，并在模型选项描述与开关之间增加了间距。

## 修复

- 更快地加载 Claude 历史记录和 Git 状态，并在网络未更改时在 Android 上复用最近的 DNS 查询。
- 在聊天工具卡片中，每个命令或工具输入仅显示一次。
- 从归档返回时，回到先前查看的列表。
- 新的 Antigravity 对话现在会显示其模型名称。
- Codex 缓存详情现在会显示预计节省金额。

- Android — `remote-code-v0.18.11.apk`
