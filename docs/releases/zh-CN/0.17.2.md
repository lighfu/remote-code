# Remote Code 0.17.2

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.17.2.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.17.2.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.17.2.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.17.2.md)

- 重复启动时，可选择“停止现有服务端并启动”或“取消本次启动”。
- 未输入选择或以非交互方式启动时，保留现有服务端。
- 在应用 0.17.5 中添加服务端下载按钮和链接分享按钮。
- 支持日语、英语、简体中文、繁体中文和韩语。Android 13 及以上可在应用内切换语言，Android 10–12 跟随设备语言。
- 使用专用卡片显示 Claude 会话间的消息，并可将回复加入草稿。
- 支持分别切换工具输入和输出的自动换行。
- 紧凑显示 Git 变更列表。
- 分别设置界面、聊天正文和代码的字体，并通过对话框选择。

请使用新版 ZIP 获得停止现有服务端的选项。如果正在运行的旧版尚未支持远程停止，请先在对应终端中按 Ctrl+C，再启动新版。
