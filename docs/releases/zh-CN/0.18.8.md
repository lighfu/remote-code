# 0.18.8

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.18.8.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.18.8.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.18.8.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.18.8.md)

发布 Windows 服务端 0.18.8 和 Android 应用 0.17.10（构建号 57）。

## 变更

- 将 Codex Desktop 的模型、推理强度和 Fast 模式更新合并为一次请求。

## 修复

- 保留 Android 加载会话历史期间收到的回复和审批卡片。
- Codex Desktop 接受消息后，清除 Android 输入框中已发送的正文和附件，并保留发送期间编辑的草稿。
- 修复会话列表预览恢复为旧消息或子代理输出的问题。
- 恢复 Codex 快速提问（`/btw`）的历史保存，并在答案完成后立即显示。
- 修复 Codex 正在工作的会话重新连接、停止操作、计划、问题和生成图片的预览。
- 修复 Claude PC 会话的工作状态、计划审批、上下文详情和缓存统计。
- 恢复 Antigravity 的问题回答功能，并分开显示连续轮次中的回复和思考。
- 保留从 Android 打开的终端滚动历史，并立即应用终端大小调整。
- 修复旧版 APK 分发、Windows 便携版启动和异常退出后的恢复，以及 Quick Tunnel 进程退出后的重试。

Android 应用可通过服务端的 **App QR** 更新。
