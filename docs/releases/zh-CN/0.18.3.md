# 0.18.3

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.18.3.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.18.3.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.18.3.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.18.3.md)

- 将 Windows 服务端迁移至 Go。解压发行版 ZIP 后，可通过 `start.cmd` 启动。
- 在终端中显示连接二维码和应用二维码。显示空间不足时，会在支持的终端中自动扩大窗口。
- 修复 Codex、Claude 和 Antigravity 的上下文详情、Codex 的缓存统计以及 Antigravity 的模型名称显示。
- Codex Desktop 执行任务期间，即使服务端重新启动并等待重新连接，也会保留正在工作的状态。
- 随附已签名的 Android 应用 0.17.8。修复会话排序和重新连接时的状态更新，并将单行的“思考内容”默认折叠。

从旧 Node.js 版本迁移时，请先停止旧服务端，将新的 ZIP 解压到另一个文件夹，复制旧文件夹中的 `data`，然后运行 `start.cmd`。Android 应用可通过终端中的 **App QR** 安装或更新。
