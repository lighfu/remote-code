# 0.19.9

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.19.9.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.19.9.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.19.9.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.19.9.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.19.9.md)

Windows 服务端版本 **0.19.9**，Android 应用版本 **0.18.9**（内部版本 **68**）。

## 新增

- 在 Android 上的远程桌面中收听 Windows PC 的播放音频。
- 在 PC 历史记录新增的“全部”标签页中，集中搜索、排序并打开 Claude、Codex 和 Antigravity 对话。
- 在 Git 界面中根据更改生成可编辑的提交信息。

## 变更

- 远程桌面现默认采用 30 FPS 原生分辨率，并启用清晰像素缩放、剪贴板同步及 PC 音频。
- 使用右上角的聊天菜单更改思考过程和工具详情的显示方式，或切换工具输入、工具输出、文件以及 Git diff 的自动换行。更改设置时菜单保持打开状态。
- 在聊天变更卡片中一次性展开多个文件的差异。
- 现可在终端列表中查看完整命令，并通过各终端的 × 按钮将其关闭。
- 在“设置”中，已安装的服务器依赖项名称旁现已显示勾选标记。

## 修复

- 更快地加载 Claude 历史记录和 Git 状态，并在网络未更改时在 Android 上复用最近的 DNS 查询。
- 在聊天工具卡片中，每个命令或工具输入仅显示一次。
- 从归档返回时，回到先前查看的列表。

## 下载

- Windows x64 — `remote-code-v0.19.9-win32-x64.zip`
- Android — `remote-code-v0.18.9.apk`
