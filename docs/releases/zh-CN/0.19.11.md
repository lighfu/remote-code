Windows 服务端版本 **0.19.11**，Android 应用版本 **0.18.13**（内部版本 **72**）。

## 新增

- Android 聊天现在可渲染行内和独立成块的 LaTeX 公式。

## 修复

- 通过 Claude 的 `SendUserFile` 新附加的视频，在 Claude 清理临时文件后仍可播放。
- 如果在 PC 上找不到视频文件，Android 应用会提示重新附加。

- Windows x64 — `remote-code-v0.19.11-win32-x64.zip`
- Android — `remote-code-v0.18.13.apk`
