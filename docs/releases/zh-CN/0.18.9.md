# 0.18.9

Windows 服务端 **0.18.9** 与 Android 应用 **0.17.11**（构建 **58**）。

## 新增

- 从服务端仪表盘或 Android 设置安装 Claude Code、Codex、Antigravity CLI 和 cloudflared。
- 繁体中文 README 与发布说明。

## 变更

- 优先使用 WinGet，并以经过验证的官方 Windows 下载作为备选。
- 将已加载的 Claude 技能与用户消息分开显示，并保留完整内容。

## 修复

- 恢复 Claude 问题选项，防止消息和思考块重复。
- 依赖项安装后刷新提供商可用性并启动 Quick Tunnel。

## 下载

- Windows x64: `remote-code-v0.18.9-win32-x64.zip`.
- Android: `remote-code-v0.17.11.apk`.
