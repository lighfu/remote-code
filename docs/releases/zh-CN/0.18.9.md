# 0.18.9

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.18.9.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.18.9.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.18.9.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.18.9.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.18.9.md)

Windows 服务器 **0.18.9** 与 Android 应用 **0.17.11**（构建 **58**）。

## 新增

- 支持从服务器仪表盘的 **5 Setup** 标签页或已连接 Android 应用的设置中安装 Claude Code、Codex、Antigravity CLI 和 cloudflared。两端均会显示安装进度、错误和重试控件。
- 新增繁体中文 README 与本地化的发布卡片。

## 变更

- 依赖项安装优先使用用户范围的 WinGet 包。当 WinGet 不可用或无法完成安装时，安装程序会使用各提供商官方的原生 Windows 下载文件，校验其校验和，并检查已安装的 CLI 能否启动。代理账号登录在 PC 上进行。
- 已加载的 Claude 技能会与用户消息分开，在各自的卡片中显示完整内容。已导入的现有技能消息会使用原始会话记录进行修复。

## 修复

- 新安装的 CLI 无需重启服务器即可被检测到。安装 cloudflared 后会启动此前请求的 Quick Tunnel，且不会创建重复的隧道工作进程。
- Claude 的下一步提问现在会在应用中显示回复选项，同时保留原始工具输入和输出。
- 防止当同一响应通过流式传输和多条会话记录行到达时产生重复的 Claude 消息和思考块。正常的重复消息保持不变。
- 防止安装成功后仍保留过期的提供商可用性状态，并防止来自仪表盘和应用的安装请求发生重叠。

## 下载

- Windows x64: `remote-code-v0.18.9-win32-x64.zip`（已编译的 Go 服务器、依赖项安装程序和 Android APK）。
- Android: `remote-code-v0.17.11.apk`。
