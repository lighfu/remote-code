Windows 服务端版本 **0.19.4**，Android 应用版本 **0.18.4**（内部版本 **63**）。

## 新增

- 在 Android 端同时查看所有 Windows 远程显示器，也可以选择其中一个，以原始分辨率查看。
- 使用触控手势点击、滚动，或以指针为中心缩放。支持键盘输入与剪贴板文本同步。
- 支持设置目标码率或由应用自动调节。调试浮层可显示帧率、网络带宽、处理耗时与连接事件。

## 变更

- 在活跃对话期间，Git 状态与会话上下文的加载速度更快。
