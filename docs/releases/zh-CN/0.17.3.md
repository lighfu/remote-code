# Remote Code 0.17.3

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.17.3.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.17.3.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.17.3.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.17.3.md)

- 服务端消息、日志和启动提示统一使用英语。
- 在 Android 中本地化服务端标签，并保留服务提供方返回的名称。
- 支持从文本选择菜单中将选中的会话文本加入草稿。

包含 Android 0.17.6，并继续支持现有的日语服务端数据。
