# Remote Code 0.17.0

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.17.0.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.17.0.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.17.0.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.17.0.md)

## 更新内容

- 优化代码编辑的性能，并支持切换自动换行。
- 添加原生 Markdown 预览。
- 为菜单添加圆角和分隔线，并统一使用“重新加载”这一名称。
- 在子代理运行期间显示其状态，并添加“PC 历史”标题。
- 支持在服务端启动时检查和批准更新，以及从 GitHub 获取预构建 APK。更新会等待正在执行的工作结束，更新失败时恢复到旧版本。

## 安装与更新

将 Windows ZIP 解压到新文件夹，然后打开 `start.cmd`。使用终端中的应用二维码安装 Android 应用，再扫描连接二维码。

随附的 Android 应用版本为 0.17.1（48）。服务端更新需要批准，适用于 Windows 发行版的公开稳定 Release。开发用 Git 工作副本由开发者自行更新。
