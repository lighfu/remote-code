# 0.19.10

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.19.10.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.19.10.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.19.10.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.19.10.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.19.10.md)

Windows サーバーのバージョンは **0.19.10**、Android アプリは **0.18.11**（ビルド **70**）です。

## 追加

- Android のリモートデスクトップで、Windows PC の再生音を聞けるようになりました。
- PC の履歴で「すべて」を選ぶと、Claude、Codex、Antigravity の会話をまとめて検索・並べ替えでき、そこから会話を開けます。 プロジェクトごとの一覧を一括で展開・折りたたみできます。
- Git 画面で変更されたファイルを並べ替え、変更内容から編集可能なコミットメッセージを生成できます。
- チャット入力欄の下に表示する入力・出力トークン、キャッシュ、料金を個別に選べます。チャット下部とキャッシュ詳細の換算額には、言語に応じた通貨または設定で選んだ通貨を使います。
- 送信前に添付画像や動画をタップしてプレビューし、横にスワイプして切り替えられます。

## 変更

- リモートデスクトップの初期設定をフル解像度・30 FPS に変更し、拡大時のくっきり表示、クリップボード同期、PC の音声再生をオンにしました。
- チャット右上のメニューを開いたまま、思考・ツール詳細の表示や、ツールの入力・出力、ファイル、Git 差分の折り返しを切り替えられます。
- チャットの変更カードで、複数ファイルの差分を同時に展開できます。 テキストファイルの「16進数で表示」をコードビューアー右上のメニューに移しました。
- ターミナル一覧で実行コマンドの全文を確認でき、各行の × ボタンでターミナルを終了できます。
- 設定のサーバー依存関係一覧で、インストール済みの項目名にチェックマークが付きます。
- チャット下部と詳細画面で、コンテキスト、キャッシュ、Git の変更ファイル数・行数がリアルタイムに更新されます。
- 通信ログはスクロールバーをドラッグして移動できます。
- ターミナル一覧をタイトルの直下に表示し、Git 画面の説明文を2行削除しました。モデル設定では説明とスイッチの間隔を広げました。

## 修正

- Claude の履歴と Git の状態をすばやく取得できるようにしました。Android では、同じネットワークでの接続時に直近の DNS 結果を再利用します。
- チャットのツールカードで同じコマンドやツール入力が二重に表示される問題を修正しました。
- アーカイブから戻ると、直前に表示していた一覧に戻るようになりました。
- 新しい Antigravity 会話でモデル名が表示されるようになりました。
- Codex のキャッシュ詳細に推定節約額を表示します。
