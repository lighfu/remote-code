# 0.18.1

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.18.1.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.18.1.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.18.1.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.18.1.md)

- コンソールに状態・接続 QR・APK 用 QR・ログの切り替えを追加。
- マウス、矢印キー・Enter、ショートカットで操作できます。
- `R` で再起動、`Q` で終了。確認後、処理中のリクエストと会話の保存を待ちます。
- `--no-ui` で通常のログ表示に切り替えられます。
