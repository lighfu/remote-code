# 0.19.25

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.19.25.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.19.25.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.19.25.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.19.25.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.19.25.md)

Windows サーバー **0.19.25**、Android アプリ **0.18.26**（ビルド **85**）。

## 追加

- Claude のワークフローでサブエージェントの進捗と会話を確認できます。記録があればトークン使用量も表示します。
- 複数の PC を登録し、PC の履歴画面から接続先を切り替えられます。
- チャットで 1 ファイルにつき最大 512 MiB を添付でき、アップロードの進捗を表示します。
- セッション全体のキャッシュヒット率をヒートマップで確認できます。
- バックグラウンドでシェルコマンドを実行中の Antigravity チャットを作業中の一覧に残せます。

## 変更

- リモートデスクトップを拡大中、細かいカーソル移動では表示範囲が動かなくなりました。2 本指スクロールは短いスワイプで始まります。
- 2 回目のタップを長押しするか、そのまま指を動かすとドラッグが始まります。接続が切れた場合はサーバーがボタンを解放します。
- Android のダウンロード容量を減らし、Git の概要、チャット、設定の画面を整理しました。

## 修正

- 動画のストリーミングに失敗した場合は、一時ダウンロードから再生を試みます。
- 変更ファイルを開く際の問題を修正しました。プロジェクトのファイル一覧に戻ると前のフォルダーを表示し、短いコードのミニマップが引き伸ばされることも防ぎます。
- Antigravity の実行中のセッションに権限の変更を反映します。
- Claude チャットで最初の「ちょっと質問」が失敗する問題を修正し、PC のログイン情報が変わった際の Remote Control のメッセージ送信を改善しました。

## ダウンロード

- Windows x64 — `remote-code-v0.19.25-win32-x64.zip`
- Android — `remote-code-v0.18.26.apk`
