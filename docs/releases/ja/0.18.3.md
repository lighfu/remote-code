# 0.18.3

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.18.3.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.18.3.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.18.3.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.18.3.md)

- Windows サーバーを Go に移行しました。配布 ZIP を展開し、`start.cmd` で起動できます。
- ターミナルから接続用 QR とアプリ用 QR を表示できます。QR の表示領域が不足すると、対応するターミナルではウィンドウを自動で広げます。
- Codex・Claude・Antigravity のコンテキスト詳細、Codex のキャッシュ集計、Antigravity のモデル名表示を修正しました。
- Codex Desktop が作業している間は、サーバーを再起動して再接続を待つ間も作業中の状態を保持します。
- 署名済み Android アプリ 0.17.8 を同梱します。セッションの表示順と再接続時の状態更新を修正し、1行に収まる「考えたこと」は初期状態で折りたたみます。

旧 Node.js 版から移行する場合は、旧サーバーを終了し、新しい ZIP を別のフォルダーに展開してください。旧フォルダーの `data` をコピーしてから `start.cmd` で起動します。Android アプリはターミナルの **App QR** からインストール・更新できます。
