# 0.18.9

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.18.9.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.18.9.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.18.9.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.18.9.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.18.9.md)

Windows サーバー **0.18.9**、Android アプリ **0.17.11**（ビルド **58**）。

## 追加

- サーバーダッシュボードまたは Android 設定から Claude Code、Codex、Antigravity CLI、cloudflared をインストール可能に。
- 繁体字中国語の README とリリースノート。

## 変更

- WinGet を優先し、フォールバックとして検証済みの公式 Windows ダウンロードを使用。
- 読み込まれた Claude スキルをユーザーメッセージと分けて表示し、全文を保持。

## 修正

- Claude の質問選択肢を復元し、メッセージとシンキングブロックの重複を防止。
- 依存関係のインストール後にプロバイダーの利用可否を更新し、Quick Tunnel を起動。

## ダウンロード

- Windows x64: `remote-code-v0.18.9-win32-x64.zip`.
- Android: `remote-code-v0.17.11.apk`.
