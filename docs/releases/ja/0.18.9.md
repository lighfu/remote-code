# 0.18.9

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.18.9.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.18.9.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.18.9.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.18.9.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.18.9.md)

Windows サーバー **0.18.9** および Android アプリ **0.17.11**（ビルド **58**）。

## 追加

- サーバーダッシュボードの **5 Setup** タブ、または接続中の Android アプリの設定から、Claude Code、Codex、Antigravity CLI、cloudflared をインストールできるようになりました。いずれの画面でも、インストールの進行状況、エラー、再試行コントロールが表示されます。
- 繁体字中国語の README とローカライズされたリリースカードを追加しました。

## 変更

- 依存関係のセットアップでは、ユーザースコープの WinGet パッケージを優先します。WinGet が利用できない場合やインストールを完了できない場合は、各プロバイダーの公式ネイティブ Windows ダウンロードを使用し、チェックサムを検証したうえで、インストールされた CLI が起動することを確認します。エージェントアカウントへのサインインは PC 上で行います。
- 読み込まれた Claude スキルは、ユーザーメッセージとは別に、全文を含む個別のカードとして表示されるようになりました。既存のインポート済みスキルメッセージは、元のトランスクリプトを使用して修復されます。

## 修正

- 新しくインストールされた CLI が、サーバーを再起動せずに検出されるようになりました。cloudflared をインストールすると、重複するトンネルワーカーを作成することなく、以前に要求された Quick Tunnel が開始されます。
- Claude の次のステップに関する質問で、元のツールの入力と出力を保持したまま、アプリ内に返信の選択肢が表示されるようになりました。
- 1つの応答がストリーミングと複数のトランスクリプト行を通じて届いた際に、Claude のメッセージや思考ブロックが重複するのを防ぎました。正当な繰り返しメッセージはそのまま維持されます。
- インストール成功後に古いプロバイダー利用可否状態が残るのを防ぎ、ダッシュボードとアプリからのインストール要求が重複しないようにしました。

## ダウンロード

- Windows x64: `remote-code-v0.18.9-win32-x64.zip`（コンパイル済み Go サーバー、依存関係インストーラー、Android APK）。
- Android: `remote-code-v0.17.11.apk`。
