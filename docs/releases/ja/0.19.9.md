# 0.19.9

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.19.9.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.19.9.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.19.9.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.19.9.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.19.9.md)

Windows サーバーのバージョンは **0.19.9**、Android アプリは **0.18.9**（ビルド **68**）です。

## 追加

- Android のリモートデスクトップで、Windows PC の再生音を聞けるようになりました。
- PC の履歴で「すべて」を選ぶと、Claude、Codex、Antigravity の会話をまとめて検索・並べ替えでき、そこから会話を開けます。
- Git 画面で変更内容から編集可能なコミットメッセージを生成できます。

## 変更

- リモートデスクトップの初期設定をフル解像度・30 FPS に変更し、拡大時のくっきり表示、クリップボード同期、PC の音声再生をオンにしました。
- チャット右上のメニューを開いたまま、思考・ツール詳細の表示や、ツールの入力・出力、ファイル、Git 差分の折り返しを切り替えられます。
- チャットの変更カードで、複数ファイルの差分を同時に展開できます。
- ターミナル一覧で実行コマンドの全文を確認でき、各行の × ボタンでターミナルを終了できます。
- 設定のサーバー依存関係一覧で、インストール済みの項目名にチェックマークが付きます。

## 修正

- Claude の履歴と Git の状態をすばやく取得できるようにしました。Android では、同じネットワークでの接続時に直近の DNS 結果を再利用します。
- チャットのツールカードで同じコマンドやツール入力が二重に表示される問題を修正しました。
- アーカイブから戻ると、直前に表示していた一覧に戻るようになりました。

## ダウンロード

- Windows x64 — `remote-code-v0.19.9-win32-x64.zip`
- Android — `remote-code-v0.18.9.apk`
