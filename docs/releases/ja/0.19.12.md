# 0.19.12

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.19.12.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.19.12.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.19.12.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.19.12.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.19.12.md)

Windows サーバーのバージョンは **0.19.12**、Android アプリは **0.18.13**（ビルド **72**）です。

## 修正

- Windows ポータブル版で `R` キーを押すと、再起動時に更新を確認し、新しいバージョンがあればインストールするかを尋ねます。
- 更新を確認できなかった場合は、コンソールにその旨を表示します。

0.19.11 以前からこの修正を適用するには、サーバーを停止してから `start.cmd` をもう一度実行し、更新を承認してください。

## ダウンロード

- Windows x64 — `remote-code-v0.19.12-win32-x64.zip`
- Android — `remote-code-v0.18.13.apk`
