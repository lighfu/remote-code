# Remote Code 0.17.4

- ネイティブのディレクトリパス解決に対応していない Windows RAM ディスクで、起動と更新が失敗する問題を修正しました。
- リンク先の境界チェックを保持し、パスの大文字・小文字が異なる場合も同じインストールとして認識します。

ランチャーが起動できない場合は、新しい ZIP を展開して置き換えてください。Android 0.17.6 を同梱します。
