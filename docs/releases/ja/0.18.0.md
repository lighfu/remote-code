# 0.18.0

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.18.0.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.18.0.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.18.0.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.18.0.md)

- サーバーを Go に移行。Node.js の導入・同梱は不要です。
- Claude Code は PC のインストール済み実行ファイルを使用します。配布物には含みません。
- 会話・承認・履歴・使用量・ファイル・Git・ターミナル・配布更新を移植しました。

旧 Node.js 版からは、サーバーを終了して新しい ZIP を別フォルダーへ展開し、旧フォルダーの `data` をコピーしてください。`start.cmd` で起動します。

Android アプリは署名済み 0.17.6 を同梱します。
