# 0.18.8

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.18.8.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.18.8.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.18.8.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.18.8.md)

Windows サーバー 0.18.8 と Android アプリ 0.17.10（ビルド番号 57）を配布します。

## 変更

- Codex Desktop のモデル・推論の強さ・Fast モードの更新を1回のリクエストにまとめました。

## 修正

- Android の履歴読み込み中に届いた返信と承認カードを保持するよう修正しました。
- Codex Desktop で受理された本文と添付を Android の入力欄から消し、送信中に編集した下書きを保持するよう修正しました。
- 会話一覧のプレビューが古いメッセージや子エージェントの出力へ戻る問題を修正しました。
- Codex の短い質問（`/btw`）の履歴保存を復元し、回答が完成した時点で表示するよう修正しました。
- Codex の作業中の会話への再接続、停止、プラン、質問、生成画像のプレビューを修正しました。
- Claude の PC セッションの作業状態、プラン承認、コンテキスト詳細、キャッシュの集計を修正しました。
- Antigravity の質問への回答を復元し、連続するターンの返答と思考を分けて表示するよう修正しました。
- Android から開いたターミナルのスクロール履歴を保持し、サイズ変更をすぐに反映するよう修正しました。
- 旧版の APK 配信、Windows ポータブル版の起動と異常終了後の復帰、Quick Tunnel のプロセス終了後の再試行を修正しました。

Android アプリはサーバーの **App QR** から更新できます。
