# Remote Code 0.17.0

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.17.0.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.17.0.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.17.0.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.17.0.md)

## 変更点

- コード編集を軽量化し、折り返し表示の切り替えに対応。
- Markdown のネイティブプレビューを追加。
- メニューの角丸・区切り線を追加し、「再読み込み」に表記を統一。
- サブエージェントを実行中から表示し、「PC の履歴」の見出しを追加。
- サーバー起動時の更新確認と承認、GitHub のビルド済み APK の取得に対応。作業中は更新を見送り、失敗時は旧版へ復帰。

## 導入・更新

Windows 用 ZIP を新しいフォルダーへ展開し、`start.cmd` を開きます。ターミナルの QR から Android アプリを導入し、接続用 QR を読み取ってください。

Android アプリは 0.17.1（48）です。サーバー更新は承認制で、Windows 配布版の公開安定 Release が対象です。開発用 Git チェックアウトには適用しません。
