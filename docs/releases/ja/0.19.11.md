# 0.19.11

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.19.11.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.19.11.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.19.11.md) · [繁體中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-Hant/0.19.11.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.19.11.md)

Windows サーバーのバージョンは **0.19.11**、Android アプリは **0.18.13**（ビルド **72**）です。

## 追加

- Android のチャットで、文中や独立した行に書かれた LaTeX の数式を表示できます。

## 修正

- Claude の `SendUserFile` で新たに添付した動画は、Claude が一時ファイルを削除した後も再生できます。
- PC 上に動画ファイルが見つからない場合、Android アプリに再添付の案内を表示します。

## ダウンロード

- Windows x64 — `remote-code-v0.19.11-win32-x64.zip`
- Android — `remote-code-v0.18.13.apk`
