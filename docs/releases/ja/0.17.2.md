# Remote Code 0.17.2

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.17.2.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.17.2.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.17.2.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.17.2.md)

- 二重起動時に「既存を停止して起動／今回の起動を中止」を選択。
- 未入力・非対話では既存サーバーを維持。
- アプリ 0.17.5 にサーバーのダウンロード・リンク共有ボタンを追加。
- 日本語・英語・簡体字中国語・繁体字中国語・韓国語に対応。Android 13 以降はアプリ内で切り替え、10–12 は端末の言語に追従。
- Claude のセッション間メッセージを専用カードに表示。返信文を下書きへ追加。
- ツールの入力・出力を個別に折り返し切り替え。
- Git の変更一覧をコンパクトに表示。
- UI・チャット本文・コードのフォントを分離し、選択をダイアログ化。

配布版の停止選択には新しい ZIP を使ってください。制御に未対応の旧版が起動中の場合は、そのターミナルで Ctrl+C を押してから起動します。
