Windows server **0.19.4** and Android app **0.18.4** (build **63**).

## Added

- View all Windows displays together or select one at full resolution from Android.
- Click and scroll with touch gestures, and zoom around the pointer. Type with the keyboard or sync clipboard text.
- Set a target bitrate or let the app adjust it. The debug overlay shows frame rate, bandwidth, processing time and connection events.

## Changed

- Git status and session context load faster during active conversations.
