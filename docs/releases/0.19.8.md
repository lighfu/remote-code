Windows server **0.19.8** and Android app **0.18.7** (build **66**).

## Added

- Navigate source files and diffs with a draggable code minimap.
- Inspect binary files in hexadecimal and jump directly to a byte offset.
- See the affected files on a chat change card and open each file directly.

## Fixed

- Show line numbers in chat previews of newly created files.
- Reduce delays for Codex quick questions in long conversations and show streamed answers as they arrive.
