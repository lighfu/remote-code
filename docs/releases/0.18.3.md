# 0.18.3

[English](https://github.com/lighfu/remote-code/blob/main/docs/releases/0.18.3.md) · [日本語](https://github.com/lighfu/remote-code/blob/main/docs/releases/ja/0.18.3.md) · [简体中文](https://github.com/lighfu/remote-code/blob/main/docs/releases/zh-CN/0.18.3.md) · [한국어](https://github.com/lighfu/remote-code/blob/main/docs/releases/ko/0.18.3.md)

- Migrate the Windows server to Go. Extract the distribution ZIP and open `start.cmd` to start it.
- Display connection and app installation QR codes in the terminal. Supported terminals automatically enlarge the window when a QR code needs more space.
- Fix context details for Codex, Claude, and Antigravity, Codex cache statistics, and Antigravity model names.
- Preserve the working state of active Codex Desktop conversations while the server restarts and waits to reconnect.
- Include the signed Android 0.17.8 APK. Fix session ordering and state updates after reconnecting. Single-line thinking entries start collapsed.

To migrate from the Node.js version, stop the old server and extract the new ZIP into a separate folder. Copy `data` from the old folder, then open `start.cmd`. Install or update the Android app using **App QR** in the terminal.
