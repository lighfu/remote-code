Windows server **0.19.12** and Android app **0.18.13** (build **72**).

## Fixed

- On the Windows portable server, pressing `R` now checks for updates during restart and asks before installing an available update.
- The console reports when it cannot check for updates.

To install this fix from 0.19.11 or earlier, stop the server, run `start.cmd` again, and accept the update.
